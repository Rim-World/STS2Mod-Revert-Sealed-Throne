# ADR-001：封印王座升级效果回调的实现方案

- 日期：2026-08-17
- 状态：**已实施**（v1.0 已构建并安装至游戏 mods 目录，2026-08-17）

## 背景

储君先古卡「封印王座」（TheSealedThrone）在 v0.107.1+ 的升级效果为「费用 -1」，v0.106 及之前为「添加固有」。用户要求将该卡升级效果固定回调为「固有」，适配 107 与 111，且面向未来版本尽量无感兼容。

## 决策

1. **补丁面最小化**：仅补丁 `TheSealedThrone.OnUpgrade`（Prefix，`AddKeyword(CardKeyword.Innate)` + `return false`）。基础版行为、OnPlay、Power、卡图、本地化一律不动（CardKeyword 注释保证关键字自动渲染进描述，无需文本补丁）。
2. **技术栈沿用系列模板**：Godot.NET.Sdk/4.5.1 + net9.0 + HarmonyLib，`[ModInitializer("ModLoaded")]` 入口，`Harmony.PatchAll` 外包 try/catch（签名变化时 mod 静默失效）。
3. **运行时防护**：轻量形状守卫（`ModelDb.Card<TheSealedThrone>()` 校验费用 1 / 星费 3 / Power / Ancient / 升级前不含 Innate），不符则禁用补丁并 Log.Warn；补丁内幂等检查（已含 Innate 则放行原实现），防止未来官方改回固有时重复加固有。
4. **manifest**：`min_game_version = "0.107.1"`；无资源，先试 `has_pck = false, has_dll = true`（若加载器不接受再补空 pck）。
5. **不引入 ModConfig**：固定回调，无玩家配置项（与 calculated-gamble 最小化决策一致）。
6. **版本兼容验证方式**：单份产物同时服务 107/111（已取证两版目标卡与依赖 API 一致）；每次游戏更新后按比对清单复查。

## 备选方案（未采纳）

- 复用 STS2Revertantony 的版本配置机制（玩家可切换 99.1/103.2/现行）：功能过剩，违背"固定回调 + 最小化"目标。
- Patch `CardModel.OnUpgrade` 基类 Postfix：本卡在 107/111 均 override 了 OnUpgrade，派生类 Patch 更直接（STS2RevertAnthony 规则：override 的成员 patch 派生类）。
