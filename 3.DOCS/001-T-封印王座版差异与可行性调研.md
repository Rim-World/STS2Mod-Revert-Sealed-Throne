# 调研：封印王座（The Sealed Throne）升级效果版本差异与回调可行性

- 日期：2026-08-17
- 目标：确认「升级减费 → 升级加固有」的回调所需全部信息，无需用户提供 106 版游戏文件

## 一、结论速览

- 只补丁 1 处（`TheSealedThrone.OnUpgrade`），加 `CardKeyword.Innate` 并跳过原实现，即可完成回调。
- 无需本地化修改（关键字自动渲染进描述）。
- 107 与 111 中目标卡与所依赖 API 完全一致，单份产物双版本通用。
- 参考实现已有两处先例（STS2RevertAnthony、CustomCardBalance），实现风险极低。

## 二、版本证据

### 2.1 目标卡定义（107 与 111 逐字一致）

```csharp
public sealed class TheSealedThrone : CardModel
{
    public override int CanonicalStarCost => 3;

    public TheSealedThrone() : base(1, CardType.Power, CardRarity.Ancient, TargetType.Self) { }

    protected override async Task OnPlay(PlayerChoiceContext choiceContext, CardPlay cardPlay)
    {
        await CreatureCmd.TriggerAnim(base.Owner.Creature, "PowerUp", base.Owner.Character.PowerUpAnimDelay);
        await PowerCmd.Apply<TheSealedThronePower>(choiceContext, base.Owner.Creature, 1m, base.Owner.Creature, this);
    }

    protected override void OnUpgrade() { base.EnergyCost.UpgradeBy(-1); } // ← 107/111 现行
}
```

- 归属：REGENT（储君）卡池（`RegentCardPool`），Ancient（先古）稀有度，3 星费（CanonicalStarCost）。

### 2.2 旧版升级实现（目标效果）

diff 证据（`refs/STS2RevertAnthony/code-v0.103.2-v0.107.1-cards.diff:9972-9997`）：

```
-   protected override void OnUpgrade() { AddKeyword(CardKeyword.Innate); }   // v0.103.2（v0.99.1 同）
+   protected override void OnUpgrade() { base.EnergyCost.UpgradeBy(-1); }    // v0.107.1
```

- v0.106 无解包数据；用户确认 ≤106 升级为固有，与 103.2 数据吻合。
- STS2RevertAnthony README 表格：The Sealed Throne 升级 = 107.1「-1 cost」/ 103.2、99.1「Innate」。

## 三、API 取证（107 / 111）

| API | 位置 | 两版一致性 |
|---|---|---|
| `CardKeyword` 枚举（None=0, Exhaust=1, Ethereal=2, Innate=3, …） | `MegaCrit.Sts2.Core.Entities.Cards` | 完全相同 |
| `CardModel.AddKeyword(CardKeyword)` | CardModel.cs:1330 | 一致（110→111 比对亦确认） |
| `CardModel.Keywords`（含 `LocalKeywords`，Set 语义） | CardModel | 一致 |
| `ModInitializerAttribute` / `Log` | Modding / Logging | 一致 |

`AddKeyword` 实现：`AssertMutable(); LocalKeywords.Add(keyword); KeywordsChanged?.Invoke();`——升级流程中调用合法（Arsenal 等官方卡先例）。

## 四、本地化

无需修改。官方注释（CardKeyword.cs）：「keywords … also automatically add some extra text to the card's description」。`AddKeyword(Innate)` 后「固有」徽记/文本由 UI 自动渲染，升级预览与图鉴同步正确。STS2RevertAnthony 对 TheSealedThrone 也仅 patch OnUpgrade，未动描述。
