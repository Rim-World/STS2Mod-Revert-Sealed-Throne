# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ① 效果

将储君的先古卡“封印王座”升级后的效果由“费用减少 1”回调为“固有”（106 版本及之前的效果），其余效果保持不变。

本 mod 直接在“封印王座”原卡牌上进行修改，并非生成新卡牌 + 禁用旧卡牌。

## ② 影响（基于本人游戏理解）

“封印王座”是一张完全改变抓牌思路的核心牌，比一般的关键能力牌还要关键得多。

去除其固有属性是对整个卡组的巨大削弱，而回调则令其重返储君第一能力牌的位置。

本 mod 影响存档：mod 开启时，历史记录中的“封印王座”显示为回调后的版本；关闭 mod 后会恢复原状。

## ③ 环境与版本

本 mod 不依赖任何基础 mod。

本 mod 支持 0.107.1 及以上版本（default 107 与 beta 111 均适用）。

游戏启动时 mod 检测游戏包体中的封印王座卡牌形态（费用、稀有度、关键字等），若卡牌被移除或形态改变，本 mod 会自动禁用；

本 mod 不检测游戏分支，default 正式版与 public beta 均生效。

理论上只要没有大的 api 更新或卡牌修改，本 mod 无须修改即可自动适配新版本。

## ④ 实现方式与兼容性

本 mod 采用最小依赖的方式写成，正常来说与大多数 mod 兼容，且不易随着版本变化而失效。

但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
