## ① Effect

Reverts the upgrade effect of the Regent's Ancient card "The Sealed Throne" from "-1 cost" back to "Innate" (the effect from before v0.106). Everything else remains unchanged.

This mod modifies "The Sealed Throne" in place — it does not create a new card and disable the old one.

## ② Impact (based on my understanding of the game)

"The Sealed Throne" is a core card that completely changes how you draft your deck — far more pivotal than your average key power card.

Removing its Innate was a massive nerf to any deck built around it, while this reversion restores it to its rightful place as the Regent's #1 power card.

This mod affects saves: while the mod is enabled, "The Sealed Throne" cards in your run history display the reverted version; disabling the mod restores the original behavior.

## ③ Environment & Versions

This mod does not depend on any base mod.

This mod supports v0.107.1 and above (both default 107 and beta 111).

On startup, the mod checks the shape of "The Sealed Throne" card in the game package (cost, rarity, keywords, etc.). If the card is removed or its shape changes, the mod will disable itself automatically.

This mod does not check the game branch — it works on both the default release and the public beta.

In theory, as long as there are no major API updates or card changes, this mod should adapt to new versions automatically without any modification.

## ④ Implementation & Compatibility

This mod is written with minimal dependencies, so it should be compatible with most mods and is unlikely to break as the game updates.

However, this mod does not guarantee compatibility with pirated, modified, mobile, or outdated versions of the game, nor with niche or secondary mods.
